### 🚀 Featured personal project

#### 🧾 Lekha Tracker — Receipt Analyzer

**An independent project exploring how AI can make everyday expense tracking simpler.**

**What it demonstrates:** end-to-end product ownership, application/backend engineering, AI-assisted receipt analysis, and delivering an application on my own domain.
